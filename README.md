# Cartão Online - Professor Ronaldo

Este é um cartão de campanha online desenvolvido para o Professor Ronaldo, permitindo o compartilhamento de suas propostas de forma sofisticada e exclusiva.

## Como Executar

1. Clone o repositório:

    ```bash
    git clone https://github.com/JonatasVieiraa/LP-Ronaldo.git
    ```

2. Acesse o diretório:

    ```bash
    cd LP-Ronaldo
    ```

3. Abra o `index.html` no navegador para visualizar o cartão.

## Estrutura do Projeto

- **index.html**: Estrutura do cartão online.
- **styles.css**: Estilos customizados para um visual sofisticado.
- **script.js**: Contém interações e funcionalidades extras.
